# Bugrock Ghost Block Fixer

A Minecraft plugin designed to fix ghost blocks in Bugrock.

## Features

- Detects and removes ghost blocks
- Configurable settings
- Lightweight and efficient

## Installation

1. Build the plugin: `mvn clean package`
2. Copy the generated JAR to your server's `plugins` folder
3. Restart your server

## Configuration

Edit `plugin.yml` to customize the plugin behavior.
